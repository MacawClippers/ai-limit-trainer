## 📦 Installation

1. **Download the latest release** from the button above or the [Releases page](https://github.com/ai-limit-trainer/releases).
2. **Extract the archive** to a folder of your choice:
   ```bash
   unzip ai-limit-trainer-2026.zip -d ~/ai-limit-trainer
   ```
3. **Install dependencies** (Python 3.10+ required):
   ```bash
   pip install -r requirements.txt
   ```
4. **Run the trainer**:
   ```bash
   python trainer.py --config config.yaml
   ```
5. **Optional**: Add to PATH for global access:
   ```bash
   export PATH="$PATH:~/ai-limit-trainer"
   ```
